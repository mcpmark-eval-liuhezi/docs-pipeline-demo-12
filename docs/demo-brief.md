# docs-pipeline-demo

This repository is a clean sandbox for rehearsing our docs-pipeline demo ahead of the quarterly review.

It demonstrates the typical docs-pipeline flow: a brief intro (`docs/demo-brief.md`), working notes (`notes/scratch-notes.md`), and a minimal GitHub Actions workflow (`.github/workflows/ci.yml`) that runs on every push and prints a friendly hello line.

Use this repo to walk through the demo steps without touching any production documentation.
